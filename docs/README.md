# Documentação e evidências

Esta pasta reúne documentos internos que não são publicados no site.

- `auditoria-proveniencia-lotes/` e os arquivos `AUDITORIA_PROVENIENCIA_*`: dossiê de proveniência aprovado pelas decisões `DEC-030` e `DEC-031`.
- `auditorias/comportamental/`: auditoria comportamental reproduzível e propostas de evolução.
- `auditorias/sinteses/`: auditoria dos perfis de síntese revisados.
- `relatorios/fases/`: evidências históricas organizadas por fase.
- `relatorios/finais/`: consolidações finais históricas.

O estado vigente do projeto continua em `../PROJECT_STATUS.md`; relatórios são evidências, não substituem decisões nem comportamento executável.
